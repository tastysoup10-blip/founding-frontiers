# Founding Frontiers — Playtest

A browser-based digital playtest companion for a physical tabletop game.

## Current prototype
- 15 × 8 selectable coordinate grid (columns 1–15, rows a–h)
- Approximate hand-traced terrain layout based on the creator's colored prototype drawing
- Four provisional starting markers
- Player turn switching, Energy Points, crew placement, resource counters, and a game log

## Important
This is a playtesting prototype, not the final physical rules. Costs, movement, terrain-specific gathering, and crew-specialty bonuses are not enforced yet. The ChatGPT/MCP connection is a later phase and is not included in this static site yet.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
